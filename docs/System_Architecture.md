# Hybrid-Electric Propulsion Optimization for Fixed-Wing UAV

## Project Overview

This project aims to design and optimize a Hybrid-Electric Propulsion System for a fixed-wing UAV.

The objective is to maximize flight endurance while minimizing fuel consumption and battery usage by intelligently managing power between a gas turbine engine and an electric propulsion system.

The software simulates the complete UAV mission, monitors system performance in real time, and optimizes power distribution using computational algorithms.

---

# Objectives

- Increase flight endurance
- Reduce fuel consumption
- Improve battery efficiency
- Simulate complete UAV missions
- Build a Digital Twin of the aircraft
- Develop an optimization framework for hybrid propulsion

---

# System Components

The project consists of the following subsystems:
